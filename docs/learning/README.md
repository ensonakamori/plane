## 🧠 Key Concepts You'll Master

### Frontend Concepts

- **React Router 7 Framework Mode** - Loaders, actions, server rendering
- **MobX State Management** - Reactive state, observables, computed values
- **TypeScript Best Practices** - Type safety, generics, utility types
- **SWR Data Fetching** - Caching, revalidation, optimistic updates
- **Monorepo Architecture** - Shared packages, workspace protocol
- **Component Patterns** - Composition, render props, custom hooks
- **Performance Optimization** - Code splitting, lazy loading, memoization

### Backend Concepts (For Frontend Devs)

- **Django MTV Pattern** - Models, Templates (API), Views
- **REST API Design** - Resources, HTTP methods, status codes
- **Database Modeling** - Relations, migrations, queries
- **Authentication & Authorization** - JWT, permissions, RBAC
- **Async Task Processing** - Celery, message queues, workers
- **Caching Strategies** - Redis, query caching, CDN
- **Database Optimization** - Indexes, N+1 queries, explain plans

### Architectural Thinking

- **Separation of Concerns** - Frontend, backend, database layers
- **Data Flow** - Unidirectional vs bidirectional data flow
- **State Management** - Where state lives, when to lift up
- **API Design** - RESTful principles, versioning, pagination
- **Scaling Strategies** - Horizontal scaling, load balancing, sharding
- **Security Principles** - Authentication vs authorization, input validation
- **Observability** - Logging, monitoring, distributed tracing

## 🏗️ Understanding Plane's Architecture

**Plane is an open-source project management tool** (think Jira, Linear, or Asana).

### What Plane Does

- **Issues & Projects** - Track work items with custom fields
- **Cycles & Sprints** - Time-boxed iterations
- **Views & Filters** - Flexible ways to see your work
- **Pages & Documentation** - Wiki-style pages
- **Real-time Collaboration** - Live updates via WebSockets
- **Notifications** - Stay informed about changes
- **Analytics** - Insights into team productivity

### Architectural Highlights

```
┌─────────────────────────────────────────────────────────────┐
│                         FRONTEND                            │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐      │
│  │   Web   │  │  Admin  │  │  Space  │  │  Live   │      │
│  │  (Main) │  │ (Admin) │  │(Public) │  │(Realtime)│      │
│  └────┬────┘  └────┬────┘  └────┬────┘  └────┬────┘      │
│       │            │             │             │           │
│       └────────────┴─────────────┴─────────────┘           │
│                         │                                   │
│                    React Router 7                           │
│                    MobX + SWR                              │
│                    Shared Packages                          │
└─────────────────────────┬───────────────────────────────────┘
                          │ REST API / WebSocket
┌─────────────────────────┴───────────────────────────────────┐
│                        BACKEND                              │
│  ┌───────────────────────────────────────────────────┐     │
│  │              Django REST Framework                 │     │
│  │  ┌──────────┐  ┌───────────┐  ┌──────────────┐   │     │
│  │  │   API    │  │  Workers  │  │  WebSockets  │   │     │
│  │  │(Views)   │  │ (Celery)  │  │ (Channels)   │   │     │
│  │  └────┬─────┘  └─────┬─────┘  └──────┬───────┘   │     │
│  └───────┼──────────────┼────────────────┼───────────┘     │
│          │              │                │                  │
│  ┌───────┴──────┬───────┴────────┬───────┴──────┐          │
│  │  PostgreSQL  │     Redis      │   MongoDB    │          │
│  │ (Primary DB) │ (Cache/Broker) │ (Analytics)  │          │
│  └──────────────┴────────────────┴──────────────┘          │
└─────────────────────────────────────────────────────────────┘
```

**Key Architectural Patterns:**
- **Monorepo** - Frontend & backend in one repo with shared code
- **Microservices-ready** - Multiple apps that could run independently
- **BFF Pattern** - Backend for Frontend (API tailored for web app)
- **Polyglot Persistence** - Multiple databases for different use cases
- **Event-Driven** - Celery tasks respond to events
- **Real-time** - WebSockets for live updates

See [ARCHITECTURE_OVERVIEW.md](./ARCHITECTURE_OVERVIEW.md) for deep dive.
